CÂU HỎI 08: LÝ THUYẾT JAVASCRIPT

Câu 1: JavaScript là gì? Nó được dùng để làm gì trong thiết kế web?

1.1. Khái niệm JavaScript

JavaScript (viết tắt là JS) là một ngôn ngữ lập trình bậc cao, thông dịch (hoặc biên dịch tức thời - JIT), hướng đối tượng dựa trên nguyên mẫu (prototype-based) và hỗ trợ lập trình hàm. Cùng với HTML (xây dựng cấu trúc nội dung) và CSS (định dạng giao diện), JavaScript là một trong ba công nghệ cốt lõi của World Wide Web (WWW).

1.2. Vai trò và ứng dụng của JavaScript trong thiết kế web

  • Tạo tính tương tác cho trang web: Xử lý các sự kiện từ người dùng như nhấp chuột (click), di chuột (hover), nhập liệu bàn phím, cuộn trang để phản hồi tức thì mà không cần tải lại trang.
  • Thao tác với DOM và CSS (DOM Manipulation): Thêm, sửa, xóa các phần tử HTML và thay đổi thuộc tính CSS linh hoạt (ví dụ: đóng/mở menu, chuyển đổi chế độ Sáng/Tối, tạo hiệu ứng trượt ảnh).
  • Kiểm tra hợp lệ dữ liệu biểu mẫu (Form Validation): Xác thực định dạng email, độ dài mật khẩu, hoặc các trường bắt buộc ngay trên trình duyệt trước khi gửi dữ liệu lên máy chủ.
  • Giao tiếp bất đồng bộ với máy chủ (AJAX / Fetch API): Gửi và nhận dữ liệu nền (thường ở định dạng JSON) để cập nhật một phần nội dung trang web theo thời gian thực (như tải thêm bài viết, tìm kiếm gợi ý, cập nhật giỏ hàng).
  • Phát triển ứng dụng web hiện đại và đa nền tảng: Xây dựng các ứng dụng trang đơn (SPA) bằng các thư viện/framework như React, Vue, Angular; đồng thời mở rộng sang lập trình phía máy chủ (Node.js), ứng dụng di động và game trên trình duyệt.

Câu 2: Các kiểu dữ liệu chính trong JavaScript là những kiểu nào?

Theo chuẩn ECMAScript hiện đại, JavaScript chia các kiểu dữ liệu thành 2 nhóm chính: Kiểu dữ liệu nguyên thủy (Primitive Types) và Kiểu dữ liệu tham chiếu (Reference / Object Types).

2.1. Nhóm kiểu dữ liệu nguyên thủy (7 kiểu - Primitive Types)

Dữ liệu nguyên thủy là bất biến (immutable) và được lưu trữ trực tiếp theo giá trị:

  • Number: Biểu diễn cả số nguyên và số thực dấu phẩy động (ví dụ: 42, 3.14), cùng các giá trị đặc biệt như Infinity, -Infinity và NaN.
Lưu ý: Ảnh bạn gửi bị cắt ở phần đầu mục Number. Trang này chỉ nhập lại phần nội dung đọc được; phần tiếp theo của Câu 2 chưa có nguồn để bổ sung.
